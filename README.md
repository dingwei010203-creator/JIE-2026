# 经职 · 经济学博士招聘雷达

独立新项目，面向2026届经济学博士，广东优先，重点关注党校、政府直属及部门所属科研院所，同时覆盖江苏、浙江与北京的社科院、普通高校和职业院校。与其他招聘网站的数据、收藏和计划分别维护。

## 使用

- 首页默认显示广东仍处于公告报名期或滚动招聘期的教研、科研岗位。
- 可按地区、机构类型、岗位类型、状态及关键词筛选；党校和科研机构有快捷入口。
- 博士后单独筛选、单独统计，不混入正式教研科研条目。
- 点击书签收藏，在“我的清单”记录准备材料、已投递、面试等进度。
- CSV 导出当前筛选结果；截止日历导出 `.ics`，含提前3天提醒，需要自行导入日历应用。
- 求职条件、收藏和进度仅保存在当前浏览器，不会上传到公开仓库。

默认资格基准为2026届经济学博士，有港澳硕博学习经历。不根据本科院校的名气推断可否报考。政治面貌、年龄、具体二级专业、科研成果及工作经历未明确时，保留为需核对条件，不自动判定符合。

## GitHub 部署

独立仓库：[dingwei010203-creator/JIE-2026](https://github.com/dingwei010203-creator/JIE-2026)，默认分支为 `main`。网页、数据和每日更新流程均在本仓库维护。

1. 仓库 **Settings → Pages → Source → GitHub Actions**。
2. 在 `data/site.json` 填入实际的 `repositoryUrl`，确认 Actions 调度已启用后把 `workflowEnabled` 改为 `true`。
3. 推送到 `main` 会先核验数据，再自动部署静态网页。
4. 在 Actions 页面确认首次部署成功，使用部署结果中返回的网站地址，不把预期地址当作已上线地址。

GitHub Pages 的标准免费公开托管以实际账号计划为准。官方文档：[创建 Pages 网站](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)、[自定义部署流程](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。

## 每日更新

工作流在北京时间 **08:37** 触发（UTC `37 0 * * *`），平台调度可能延迟。也可在 Actions 手动运行。

每次定时运行会：

1. 按 `data/sources.json` 扫描已配置的官方栏目；首页型来源会尝试发现招聘栏目。
2. 读取招聘正文与可解析的 XLS、XLSX、PDF 岗位表；遵守 robots 和访问限制，限制并发与单站请求速度，不绕过验证码或访问限制。
3. 按 `data/query_plan.json` 尝试公开搜索补查。公开 RSS 是尽力而为的辅助渠道，可能受搜索引擎访问策略或索引覆盖限制；失败会保留在来源页，不作为“没有招聘”的证据。
4. 自动新增项先作为待核验线索；具体岗位以 `data/curated.json` 的逐项审核记录为准。可以由后续联网核验任务更新该文件，推送后自动重新部署。
5. 保留已审核记录，检查原文内容变化，并公开来源成功、部分成功、失败及未扫描状态。HTTP 200 不能代替资格或名额核验。
6. 保存每日数据快照并直接部署本次结果。定时任务使用 `GITHUB_TOKEN` 提交不会触发另一轮 push 部署，因此同一工作流包含部署步骤。

**目前是已配置来源的监测系统，不保证四地全部单位穷尽覆盖。** 入口扫描成功只代表该入口已访问；页面会注明实际读取的栏目和公告数量。动态页面、图片公告、受限附件需要联网或人工补充核对。关键词补查失败时，固定官方来源仍独立运行。

招聘有首批报名期及全年滚动期时分别核对，学位取得日、认证时限、公告展示有效期不能当作报名截止日期。滚动招聘原计划人数不等于剩余名额。超过14天未作实质核验的记录自动移入“待复核”，避免长期显示未经复核的在招岗位。

## 数据与统计

- `data/curated.json`：已逐项检查的岗位、综合公告和明确标注的重点线索，含证据链接、原计划人数、专业代码、应届与港澳学历要求。
- `data/candidates.json`：采集器发现的线索；不自动升级为已核验具体岗位。
- `data/exclusions.json`：已核实不相关的公告，避免下次采集重复出现。
- `data/feed.json`：供网页读取的合并结果，含扫描状态、关键词补查状态和后续公告。
- `data/history.json`：每日采集快照。每个日期只保留一个记录，重跑不增加天数。
- `data/sources.json`：来源目录与类型。高校下设研究院归入普通高校，民办智库不能直接标记为政府科研院所。

“当前教研 / 科研岗位”要求已核验至具体经济学博士岗位、在固定或滚动报名期内、最近核验未过期。人数只汇总对应岗位的明确计划人数；全校或综合招聘总数不直接当作经济学名额。与2026届申请人的资格匹配仍需单位审核，不给出未经验证的匹配分数。

## 本地运行与校验

无需前端依赖或打包服务。Python 3.12 与支持 ES Modules 的 Node.js 即可运行；文档附件读取器为可选依赖。

```bash
python -m pip install -r requirements.txt
python scripts/collect.py
python scripts/collect.py --offline
npm test
npm run check
python scripts/build.py
```

`--offline` 只合并已有数据，不伪造扫描时间或最近实质核验时间。部署目录为 `dist/`，原始源码、测试文件、配置说明不会作为站点资源发布。

标准静态服务器可用于本地查看构建结果，GitHub Actions 会自动生成和上传同一份 `dist/`。

## 维护审核记录

核验时填写具体岗位代码、对应专业与博士要求、报名起止时间、政治面貌、年龄、成果及工作经历、港澳学历认证时限、官方证据链接。仅确认综合公告、总人数或转载线索时，保持 `verifiedLevel` 为 `announcement` 或 `lead`；达到具体岗位核验标准后使用 `position`。

同一公告下不同岗位必须使用不同 `id` 与 `positionCode`。为同一公告保留 `alternateUrls` 可以防止官网与人社厅转载重复进入线索列表。原文发生变更时应读最新正文及附件，修正字段后更新 `verifiedAt`；不要仅因网址能打开就刷新该日期。
